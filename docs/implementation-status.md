更新时间：2026-10-05。当前代码以 Java 21 + Spring Boot 3.5.4 为后端，Vue 3 为前端；无账号系统，默认 H2 文件库与 `demo` 模式。

| --- | --- | --- |

| Agent | 已实现首版 | LangChain4j、受限文件工具、生成独立代码产物；live 模式调用兼容 OpenAI 协议的工具模型 |

## 本轮改动

- 清除旧平台的登录、管理员、网站生成、截图、COS、Redis 等源文件和依赖；保留科研流程所需模块，包名改为 `org.researchagent`。
- 新增项目 Markdown 文件记忆、手动文献笔记、基于 H2 的本地词项检索和任务检索事件。当前检索不使用 PgVector，也不从互联网自动抓论文。
- 工作台新增记忆与笔记编辑、手动检索及任务阶段显示。创建/批准任务仍由用户控制。
- 新增 `research/run` 的可选 Python Runner，以及 `research/paper` 的 arXiv Atom 同步；前端增加运行日志和论文列表。
- 新增浏览器专用 `/#/demo` 与手动触发的 Pages 工作流；访问者可检查交互，但不能操作真实工作区。
- `.env.example` 默认 demo；无 API 密钥也能验证完整任务链路。生成代码不会被自动运行或修改原仓库。

## 验证

- `mvnw.cmd -B -ntp verify`：5 项科研测试通过，覆盖无登录项目、路径边界、后台 demo、模拟工具模型、记忆/检索上下文及论文订阅配置。
- `frontend/npm run build`：Vue 类型检查与生产构建通过；Vite 提示主包体积较大，属于优化项。
- `scripts/smoke-demo.ps1 -EnableRunner -SyncPapers` 独立进程烟测通过：H2 v1–v3 迁移、创建项目、记忆读写、检索事件、2 个 demo 文件、Python 脚本成功执行、同步到 5 篇 arXiv 论文；脚本创建的进程已停止。
- 静态演示在浏览器中实际点击了创建、审批、事件、代码预览；Pages 远程部署未验证。
- 未验证真实模型质量、Docker、macOS/Linux、公开在线演示。

## 发布边界

- 单实例 Worker 最多同时处理两个生成任务；服务重启会将 RUNNING 标记为 INTERRUPTED。
- Python Runner 单次最多 5 分钟，默认关闭；只限制执行入口、时长和日志，不提供进程/文件/网络隔离。不能把它当作安全沙箱。
- 无认证 API 只面向可信本机。公网 demo 需要访客隔离或只读化，不可原样暴露。
- 本地两个上游仓库未见 LICENSE；公开 GitHub 前需核对剩余复用源码的授权。当前没有远程仓库，也没有公网演示链接。
- 用户要求任何卡住超过 5 分钟的测试先停止并审阅；不要用未验证结果填充简历。
